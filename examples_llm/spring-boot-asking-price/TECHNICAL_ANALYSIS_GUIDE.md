# 기술적 분석 가이드 (볼린저 밴드 + RSI)

한국투자증권 API를 활용한 볼린저 밴드와 RSI를 결합한 기술적 분석 시스템입니다.

## 📊 주요 기능

### 1. 복합 기술적 지표
- **볼린저 밴드**: 가격 변동성 분석
- **RSI**: 과매수/과매도 구간 식별
- **복합 시그널**: 두 지표를 결합한 매매 신호

### 2. 캔들스틱 차트
- 실제 주가 움직임을 캔들스틱으로 표시
- 볼린저 밴드 오버레이
- 하단에 RSI 차트 표시

### 3. 파라미터 조정
사용자가 직접 전략 파라미터를 조정할 수 있습니다:

#### 볼린저 밴드
- **이동평균 기간**: 5~50일 (기본: 20일)
- **표준편차 배수**: 1.0~3.0 (기본: 2.0)

#### RSI
- **RSI 기간**: 5~30일 (기본: 14일)
- **과매수 기준선**: 60~90 (기본: 70)
- **과매도 기준선**: 10~40 (기본: 30)

## 🚀 사용 방법

### 1. 애플리케이션 실행

```bash
# 환경 변수 설정 확인
cat .env

# 실행
./run.sh
# 또는
mvn spring-boot:run
```

### 2. 웹 UI 접속

브라우저에서 다음 URL 접속:
```
http://localhost:8080/technical-analysis.html
```

### 3. 분석 수행

1. **종목 정보 입력**
   - 종목 코드 입력 (예: 005930)
   - 종목 이름 입력 (예: 삼성전자)
   - 차트 기간 설정 (20~200일)

2. **파라미터 조정**
   - 슬라이더로 원하는 값 설정
   - 실시간으로 현재 값 확인

3. **분석 실행**
   - "분석 실행" 버튼 클릭
   - 결과 확인

4. **차트 생성**
   - "차트 생성" 버튼 클릭
   - 캔들스틱 차트 확인
   - 필요시 다운로드

## 📈 매매 시그널 해석

### 강력 매수 (STRONG BUY)
**조건**: 볼린저 밴드 하단 돌파 + RSI 과매도

```
현재가 < 하단 밴드 AND RSI < 과매도선(30)
```

**의미**:
- 가격이 평균에서 크게 벗어남
- RSI도 과매도 상태
- 반등 가능성 높음

**신뢰도**: 90%

---

### 매수 (BUY)
**조건**: 볼린저 밴드 하단 돌파 OR RSI 과매도

```
현재가 < 하단 밴드 OR RSI < 과매도선(30)
```

**의미**:
- 둘 중 하나만 충족
- 매수 고려 구간

**신뢰도**: 70%

---

### 보유 (HOLD)
**조건**: 정상 범위

```
하단 밴드 <= 현재가 <= 상단 밴드
30 <= RSI <= 70
```

**의미**:
- 정상 범위 내 거래
- 관망 또는 기존 포지션 유지

**신뢰도**: 50%

---

### 매도 (SELL)
**조건**: 볼린저 밴드 상단 돌파 OR RSI 과매수

```
현재가 > 상단 밴드 OR RSI > 과매수선(70)
```

**의미**:
- 둘 중 하나만 충족
- 매도 고려 구간

**신뢰도**: 70%

---

### 강력 매도 (STRONG SELL)
**조건**: 볼린저 밴드 상단 돌파 + RSI 과매수

```
현재가 > 상단 밴드 AND RSI > 과매수선(70)
```

**의미**:
- 가격이 평균에서 크게 상승
- RSI도 과매수 상태
- 조정 가능성 높음

**신뢰도**: 90%

## 📊 차트 읽는 법

### 상단 차트 (가격)
- **빨간 캔들**: 상승 (종가 > 시가)
- **파란 캔들**: 하락 (종가 < 시가)
- **빨간 점선**: 볼린저 밴드 상단/하단
- **초록 실선**: 볼린저 밴드 중간 (20일 이동평균)

### 하단 차트 (RSI)
- **보라색 선**: RSI 값
- **빨간 점선**: 과매수선 (기본 70)
- **파란 점선**: 과매도선 (기본 30)

## 🎛️ 파라미터 조정 전략

### 단기 트레이딩
```
볼린저 밴드 기간: 10일
표준편차 배수: 1.5
RSI 기간: 9일
```
→ 변동성에 민감하게 반응

### 중기 투자 (기본)
```
볼린저 밴드 기간: 20일
표준편차 배수: 2.0
RSI 기간: 14일
```
→ 균형잡힌 전략

### 장기 투자
```
볼린저 밴드 기간: 50일
표준편차 배수: 2.5
RSI 기간: 21일
```
→ 안정적인 시그널

### 변동성 큰 종목
```
표준편차 배수: 2.5~3.0
RSI 과매수/과매도 범위 확대 (80/20)
```
→ 잘못된 시그널 감소

### 변동성 작은 종목
```
표준편차 배수: 1.5~2.0
RSI 과매수/과매도 범위 축소 (65/35)
```
→ 민감한 반응

## 🔌 API 엔드포인트

### 1. 기술적 분석

**POST** `/api/technical-analysis/analyze`

#### 요청 Body
```json
{
  "stockCode": "005930",
  "stockName": "삼성전자",
  "bbPeriod": 20,
  "bbMultiplier": 2.0,
  "rsiPeriod": 14,
  "rsiOverbought": 70,
  "rsiOversold": 30
}
```

#### 응답
```json
{
  "stockCode": "005930",
  "stockName": "삼성전자",
  "currentPrice": 71000,
  "indicators": {
    "bollingerBands": {
      "upper": 73500,
      "middle": 70000,
      "lower": 66500,
      "stdDev": 1750,
      "bandWidth": 10.0,
      "period": 20,
      "multiplier": 2.0
    },
    "rsi": {
      "value": 55.5,
      "period": 14,
      "overboughtLevel": 70,
      "oversoldLevel": 30,
      "status": "NEUTRAL"
    },
    "combinedSignal": {
      "signal": "HOLD",
      "reason": "보유: 정상 범위 (RSI: 55.5, 밴드 내 위치)",
      "confidence": 50
    }
  }
}
```

#### 요청 Body

{

## 💡 활용 팁

### 1. 시그널 확인
강력 매수/매도 시그널은 신뢰도가 높지만, 항상 다른 지표와 병행하세요.

### 2. 파라미터 최적화
- 종목마다 최적 파라미터가 다름
- 과거 데이터로 백테스팅 권장

### 3. 손절매 설정
- 신뢰도와 무관하게 손절매는 필수
- 일반적으로 5~10% 수준

### 4. 변동성 고려
- 밴드 폭(Band Width)으로 변동성 파악
- 좁은 밴드 → 큰 움직임 임박 가능성

### 5. 다이버전스 주의
- RSI와 가격의 괴리 확인
- 추세 반전 신호일 수 있음

---

## ⚠️ 주의사항

### 리스크
1. **전략 한계**: 모든 시장 상황에 유효하지 않음
2. **거짓 신호**: 횡보장에서 잘못된 신호 발생 가능
3. **지연성**: 과거 데이터 기반이므로 지연 존재

### 권장사항
1. **분산 투자**: 단일 종목 집중 지양
2. **포트폴리오 관리**: 자금의 일부만 사용
3. **거래량 확인**: 거래량이 뒷받침되는지 확인
4. **뉴스 체크**: 기업 공시, 시장 뉴스 확인

## 📞 문제 해결

### 분석 실패
```
Error: Not enough data for technical analysis
```
→ 상장 기간이 짧은 종목 (최소 50일 필요)

### 차트 생성 실패
```
Error: Failed to create chart
```
→ `~/kis-charts` 디렉토리 권한 확인

### 시그널 이상
```
모든 종목에서 HOLD 시그널만 발생
```
→ 파라미터가 너무 보수적 (표준편차 배수 높임)
